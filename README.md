# Clinical Benefits and Denials Management - Capstone

## Overview
Capstone project analyzing high-volume pharmacy claims data to identify trends and patterns in claim denials and payments. The analysis standardizes payer, provider, and drug code (NDC) fields and delivers an interactive KPI dashboard for tracking recurring issues.

## Tools & Technologies
- **Python** – data analysis and pattern identification
- **SQL** – data extraction and querying
- **Excel Power Query** – data transformation and standardization
- **Power BI** – interactive KPI dashboard

## Approach
1. **Data Preparation** – Standardized payer, provider, and NDC fields across claim records for consistent reporting
2. **Data Quality** – Identified and resolved duplicate and null records through validation and quality control checks
3. **Analysis** – Analyzed high-volume pharmacy claims to uncover denial and payment trends
4. **Visualization** – Built an interactive Power BI KPI dashboard tracking claim denials and payment trends

## Key Deliverables
- Cleaned and standardized pharmacy claims dataset
- Interactive Power BI KPI dashboard for denials and payments
- Trend analysis of recurring claim issues
